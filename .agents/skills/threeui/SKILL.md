# ThreeUI: 3D, WebGL & Cyber Aesthetics

ThreeUI provides high-performance WebGL shaders, Three.js 3D backdrops, interactive canvas particles, and glowing futuristic card designs.

## Core Visual Patterns

1. **Cyber Hero Backdrops**:
   - Glowing gradient mesh / aurora ribbons
   - Dynamic interactive particle constellations
   - Ambient glassmorphic illumination borders
   
2. **Weekly Leaderboard Spotlight & Showcase Rails**:
   - Holographic Top-Rank badges (🥇 Gold, 🥈 Silver, 🥉 Bronze with radiant glow)
   - Real-time Velocity Meter & Growth Delta Pills
   - Live Pulse Indicators & Breakout Tags
   - Seamless horizontal sliding ticker / Spotlight cards with micro-animations

3. **Three.js / Canvas Micro-Interactions**:
   - Smooth hover lift with dynamic radial gradient follow (`mousemove` highlight)
   - Sleek glassmorphism backdrop blur (`backdrop-blur-xl bg-zinc-950/60 border border-cyan-500/20`)
   - Neon accent borders (Cyan `#06b6d4`, Emerald `#10b981`, Violet `#8b5cf6`, Amber `#f59e0b`)
